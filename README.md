# 🍫 Chocolarte – Tienda Web en WordPress

Chocolarte es una tienda virtual desarrollada con WordPress que exhibe productos artesanales de fresas cubiertas con chocolate. El sitio está pensado para mostrar los precios, los productos y permitir que el cliente contacte directamente por WhatsApp para realizar pedidos.

## 🛠 Tecnologías utilizadas

- WordPress
- Editor Gutenberg
- XAMPP (para el entorno local)

## 📋 Funcionalidades principales

- Vista de catálogo de productos con nombre, imagen y precio.
- Diseño limpio y minimalista.
- Botón para redireccionar a WhatsApp con mensaje personalizado.
- Totalmente en español.
